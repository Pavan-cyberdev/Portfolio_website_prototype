01 / BUILT AT REVA UNIVERSITY

Sentry X: Zero-Trust Security Gateway

Hackurity 2026

Zero-trust runtime security gateway that sits between a Gemini AI agent and MCP servers.

PROBLEM
Autonomous agents with tool access lack runtime isolation. Compromised agents or prompt injections in tool outputs can drop databases without oversight.
APPROACH
Inline zero-trust proxy enforcing default-deny authorization, Mission Lock, SHA-256 tool integrity checks, and output sanitation.
BUILT (24H)
FastAPI reverse-proxy with Gemini SDK & MCP schemas, SQLite transaction audit log, and real-time monitoring dashboard co-built on team Bro Code.
OUTCOME
Demonstrated live at REVA University hackathon; 3 verification scenarios below allow interactive policy evaluation.
